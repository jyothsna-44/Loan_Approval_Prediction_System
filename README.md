# 💰 Loan Approval Prediction System

## 📌 Project Overview

The **Loan Approval Prediction System** is a Machine Learning based web application that predicts whether a loan application is likely to be approved or rejected based on applicant details.

The project helps financial institutions automate the loan approval process using predictive analytics and data-driven decision making.

---

# 🚀 Features

✅ Predicts loan approval status

✅ Machine Learning based prediction system

✅ User-friendly web interface

✅ Data preprocessing and scaling

✅ Fast and accurate predictions
